# Student Management

![Project](https://img.shields.io/badge/student_management-347ac1) ![Status](https://img.shields.io/badge/status-demo-blue)

**HTML · CSS · localStorage**

A browser-based student-record demo built with HTML, CSS and JavaScript.

## ✨ Features
- Add a student's name, roll number, marks and attendance percentage.
- Search records by name.
- Delete records or clear the list with confirmation.
- Keep records in this browser using localStorage.

## 🚀 Run locally
Open `index.html`, or serve the repository with `python3 -m http.server 8080`. No package installation is needed.

## 📌 Limits
There is no login, server database or cross-device sync. Clearing browser storage removes saved records. Do not use this demo for sensitive or official student data. The current filtered-delete indexing and HTML rendering need hardening before production use.
